# Personal Portfolio Website

This is my personal portfolio website, created as part of my Day 2 project during the Veda Technology internship.

The website introduces me, my education, my technical skills, and my hobbies. I built it using basic HTML and CSS to practise web development and learn how to organise a website properly.

## About the Project

The portfolio has a simple layout with a clean white background. Visitors can read about me, check my education and skills, explore my hobbies, and find my social media profiles.

## Features

- **About Me:** A short introduction about me and my interests.
- **Education:** My academic details, including Class 10th, Class 12th, and B.Tech CSE.
- **Skills:** A section for my technical skills and what I am learning.
- **Hobbies:** My personal interests.
- **Contact:** Links to my social media and professional profiles.
- **Responsive Design:** The layout adjusts to different screen sizes.
- **Easy Navigation:** The navigation menu takes visitors directly to different sections of the page.

## Technologies Used

- HTML5 for the structure of the website.
- CSS3 for styling, layout, and responsive design.

I have kept the project simple, without using any frameworks or JavaScript.

## Project Files

```text
DAY-2/
├── index.html
├── style.css
├── profile.jpg
└── README.md
```

- `index.html` contains the content and structure of the website.
- `style.css` controls the design and layout.
- `profile.jpg` is my profile photo.
- `README.md` explains the project and how to run it.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code to run the website locally.

## What I Learned

While working on this project, I practised writing HTML, styling pages with CSS, arranging content, adding navigation links, and keeping files organised. It also helped me understand how the different parts of a simple website work together.
